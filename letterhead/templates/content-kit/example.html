A route API for the planner you already use

Subtitle

Body

1077 characters 
Since 2021, municipalities and their contractors have planned waste collection routes in the Kestrel app. From today, the same planner is also an API.

What the API does

You send the stops, the trucks and the time windows. The API sends back a route for every truck, in the order the driver drives it, with the planned arrival time at every stop. A day of one municipality takes seconds.

- The rules your planners set in the app apply to the API as they are.
- Routes come back as JSON, one list of stops per truck.
- A return stop for a missed bin can go onto a route that is already driving.

Who it is for

Software teams that build dispatch or fleet tools and want routes without writing a planner of their own. In the beta, 12 teams planned 1.4 million stops with it between June and October.

How to start

1. Ask for a key on the API page.
2. Send a test day from the examples in the documentation.
3. Compare the routes with the ones your planners made in the app.

The documentation, the examples and the pricing are on the API page: https://kestrel-labs.example/api

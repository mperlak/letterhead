# brand-tokens fixtures

Two tiny woff2 subsets (only the glyphs of "Letterhead") for the
`--font-file` test in `dev-scripts/brand-tokens-smoke.mjs`, which must pass
without network.

- `poppins-500-subset.woff2`: Poppins Medium, static, OS/2 weight 500.
- `roboto-variable-subset.woff2`: Roboto, variable, wght axis 100 to 900.

Both were downloaded from Google Fonts (`css2?family=...&text=Letterhead`)
and are published there under the SIL Open Font License 1.1, which allows
embedding and redistribution.

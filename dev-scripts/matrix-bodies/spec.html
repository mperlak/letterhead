Order Sync Specification

How orders will stay in sync between Lumen Commerce and Atlas ERP.

Status
Draft for client review
Owner
Integration team, Lumen Commerce
Audience
Atlas ERP operations
Date
June 2026

Business context

Orders are exported nightly by CSV. Campaigns oversell stock, and support reconciles mismatched states by hand. This spec describes an event-driven replacement.

Scope

Covers order creation, reservation, payment confirmation. Does not cover returns (Phase 2 document) or catalog sync. Assumes Lumen remains the order ID authority.

Flow: order placement

  1. Customer places the order in Lumen Commerce.
  2. Atlas reserves stock per line item within the 8-second SLA.
  3. Confirmation is sent once stock is held; the order is confirmed in both systems.

Requirements: order module

  • A rejected line returns a reason code the operator can see.
  • Repeated idempotency keys act as status queries, never new reservations.

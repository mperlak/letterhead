Lumen Order Sync 1.4

Release notes.

Released
June 18, 2026
Channel
Production
Changes from
1.3.2

Breaking changes and required actions

One breaking change. Consumers must enforce the sequence field: deliveries may arrive out of order, and 1.4 stops guaranteeing ordered retries. Migrate by discarding events with a lower sequence than the last processed. Deadline: before upgrading to 1.5.

Highlights

  • apple_pay joins the payment methods; no consumer action needed.
  • Retry backoff now caps at hourly, cutting duplicate-delivery load by half.

Changes by area

Webhooks

  • Added: X-Lumen-Attempt header carries the attempt number.
  • Changed: dead-letter parking after 24 hours now alerts the integration channel.
  • Fixed: signature verification no longer fails on bodies over 1 MB.

Reservations

  • Changed: rejected lines return public reason codes instead of internal names.

Known issues

  • Sandbox tenants may log a spurious rotation warning; harmless, fix in 1.4.1.

Get it / report problems

Rollout is automatic. Report problems in the shared integration channel. Previous notes: Lumen Order Sync 1.3.

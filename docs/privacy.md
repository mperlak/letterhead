# Letterhead privacy policy

Updated: 10 October 2026. Publisher: Marcin Perlak.
Contact: [Letterhead support](https://github.com/mperlak/letterhead/issues).

## Document processing

Letterhead is a packaged skill with scripts and assets. It has no hosted
Letterhead backend, analytics, telemetry, advertising or plugin login.
Its publisher does not receive your documents through ordinary creation,
brand learning or revision.

The AI host processes the notes, documents, images, feedback and brand
materials you choose to provide. These can include names, business contact
details and other personal information you place in source material.
They are used to prepare the requested document or reusable brand profile.
The host's privacy policy and account settings govern its processing,
retention and deletion; Letterhead does not set those periods.

Scripts read the task inputs and write HTML, intermediate assets and brand
profiles in the host's working environment. Profiles normally live in
`.letterhead/brand/` or `.letterhead/brands/<slug>/`. These files remain
until you delete them or the host expires the workspace. There is no
Letterhead background synchronization or automatic deletion. The HTML can
contain the supplied personal data, embedded logos, images and fonts.
Review it before forwarding it or publishing it.

Do not provide passwords, API keys, government identifiers, payment-card
information or protected health records. Use redacted source material.

## Optional network requests and recipients

- Brand learning from a selected website requests that page and relevant
  stylesheets and logo assets. The website and its asset providers receive
  ordinary request information, including the execution environment's IP
  address and requested URLs; document notes are not sent as request bodies.
- Font embedding can request selected family names and font files from
  Google Fonts and its font delivery servers. It does not upload documents.
- Requested product cards read linked shop pages and product images.
  Those sites receive ordinary request information.
- Explicitly requested publishing sends the selected HTML and its embedded
  assets to Markloop through tools the user separately connected. Markloop
  is a paid service operated by this publisher and has its own privacy
  policy, account settings and retention rules. People with a share link
  may receive access according to its sharing settings. This plugin does
  not create a Markloop account or automatically publish documents.

External services control their own request logs and retention. Letterhead
has no access to or control over those logs.

## User controls

Use local source files and bundled styles to create documents without
network requests. For offline brand learning, supply local font files for
all named families and an outlined or raster logo, or approve a bundled
font substitution. A PDF alone does not disable font downloads.

You choose the source files, destination and whether to publish. Delete
local output and brand profiles through the host's file controls. Use the
host's controls for conversations and hosted workspaces, and Markloop's
controls for files you explicitly uploaded there. Removing the plugin
alone does not delete documents you already created or shared.

## Support

GitHub issues are public. If you open one, GitHub and the publisher receive
your username, issue text and any attachments you submit. Use a minimal,
redacted reproduction; do not post confidential documents or credentials.
Support information is used to investigate and answer the issue. Public
issue history is retained on GitHub until removed using GitHub's controls,
subject to its own policies; it is not copied to a separate Letterhead
support database. Request help or removal through the support link above.

and the accompanying license texts.

You are responsible for permission to use source documents, brand assets,
fonts and images, and for reviewing generated content before relying on
it or sharing it. A document checker tests specific structural and visual
rules; it does not establish factual accuracy or full accessibility.

Document creation requires a host that supports files and Node.js 18+
code execution. Optional network workflows depend on the selected sites
being accessible and on permission to use their materials. The skill does
not bypass access controls. AI-host terms and policies apply separately.

No Letterhead account, API key or purchase is required to create and revise
HTML documents. Optional publishing to Markloop requires an existing
account and separately connected tools. Markloop is operated by the same
author and is governed by its own terms; it is not included in this plugin.
Letterhead does not offer checkout or subscription sales.

For support, report a redacted reproduction at
[GitHub issues](https://github.com/mperlak/letterhead/issues).
Do not include confidential documents or authentication secrets in a public
issue. See the [privacy policy](privacy.md) for data handling.
